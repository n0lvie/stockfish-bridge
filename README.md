# Stockfish Chess Bridge (v2.0 HvH & Tournament Edition)

Высокопроизводительный, отказоустойчивый и оптимизированный мост между современным шахматным движком **Stockfish** и шахматными платформами (**Chess.com**, **Lichess.org** и любыми веб-интерфейсами).

Спроектирован специально для режима **HvH (Bot vs. Bot / Hack vs. Hack)** турниров с экстремально жесткими временными рамками (Bullet / Blitz / UltraBullet), где критична каждая миллисекунда задержки и исключены зависания или дедлоки.

---

## ⚡ Ключевые возможности и архитектура

### 1. Серверный мост и асинхронный UCI-оркестратор (`server/bridge.py`, `server/engine.py`)
- **Саб-10мс задержка ходов:** Полностью асинхронный I/O на `asyncio` и `websockets`.
- **Изоляция пайпов:** Асинхронный сброс `stderr` процесса Stockfish во избежание переполнения буфера операционной системы и зависаний на длинных партиях.
- **Мьютексы состояний:** `_state_lock` гарантирует строгую сериализацию обновлений доски даже при лавине сообщений (>50 сообщений в секунду).
- **Динамический тайм-менеджмент (`server/time_strategy.py`):** 
  - Пропорциональное распределение времени в эндшпиле и цейтноте.
  - Режим паники при остатке < 10 секунд (пропорциональный расчет хода без риска падения по флагу).
  - Поддержка контроля времени с добавлением (increment) и без добавления.
- **Тонкая настройка мощности движка:**
  - Настройка числа потоков CPU (`--threads`).
  - Выделение памяти под хеш-таблицы (`--hash`).
  - Многопоточный анализ нескольких лучших линий (`--multipv`).
  - Поддержка эндшпильных баз Syzygy (`--syzygy`) с кроссплатформенным сохранением путей Windows (`C:\...`) и Linux.

### 2. Автоматический установщик движка (`server/downloader.py`)
- Автоматически обращается к GitHub Releases официального репозитория Stockfish.
- Детектирует архитектуру процессора и поддерживаемые инструкции (AVX-512, BMI2, AVX2, SSE4.1, ARM64/Neon).
- Скачивает наилучший бинарник, распаковывает, валидирует встроенным `bench`-тестом и помещает в `server/bin/stockfish.exe`.
- Интегрирован в скрипты `setup_windows.bat` и `start.py`.

### 3. Расширение для браузера (`extension/`, Manifest V3)
- **Chess.com и Lichess.org:** Каскадный парсинг DOM (поддержка кастомных элементов `cg-wrap`, селекторов классов, токенов фигур без коллизий).
- **Устойчивость к разрывам:** Автоматический reconnect очереди сервис-воркера MV3.
- **Мгновенное выполнение ходов:** Задержка клика снижена до минимально возможной (0–5 мс).

## 🚀 Быстрый старт

### Способ 1: Windows (в 1 клик)
Запустите файл:
```bat
setup_windows.bat
```
Скрипт проверит окружение, установит зависимости и скачает проверенную сборку Stockfish под ваш процессор.

Запуск сервера:
```bat
python start.py
```

### Способ 2: Запуск с параметрами командной строки
```bash
# Использование 8 потоков, 2048 МБ хеша, показ 2 лучших линий:
python start.py --threads 8 --hash 2048 --multipv 2

# Использование эндшпильных таблиц Syzygy:
python start.py --syzygy "C:\Chess\Syzygy;D:\Tablebases"

# Запуск в автономном тестовом режиме без внешнего движка:
python start.py --mock
```

## 🎛️ Динамическая настройка параметров во время работы (без перезапуска)

Вы можете в любой момент изменить мощность и поведение движка **прямо во время запущенного сервера**:

### 1. Интерактивная консоль в терминале
Пока `start.py` запущен, вы можете вводить команды прямо в консоль:
```text
status                 - Показать текущую мощность (потоки, память, multipv, буфер)
set threads 8          - Изменить число ядер/потоков Stockfish
set hash 2048          - Изменить размер хеш-памяти (в МБ)
set multipv 3          - Включить расчет 3 лучших ходов одновременно
set syzygy C:\Syzygy   - Подключить эндшпильные таблицы Syzygy
set buffer 1500        - Изменить запас времени на часах (в мс)
set autoplay on/off    - Включить или выключить автоматический клик ходов
set mode ext/cv        - Переключить режим (браузерное расширение или CV)
save                   - Сохранить текущие параметры в settings.json
help                   - Список доступных команд
```

### 2. Веб-панель управления (Web Dashboard)
Откройте в браузере: `http://localhost:9999/index.html`.
Все параметры (потоки, хеш, MultiPV, пути к базам, задержки) можно настраивать ползунками и применять в реальном времени нажатием кнопки **«Apply Settings»**.

### 3. Автоматический Hot-Reload через `settings.json`
Если вы отредактируете файл `server/settings.json` в любом текстовом редакторе и сохраните его, сервер автоматически обнаружит изменения и применит новые параметры к Stockfish на лету без перезапуска процесса.

## 🧩 Подключение браузерного расширения

1. Откройте в браузере (Chrome / Edge / Brave / Opera): `chrome://extensions/`
2. Включите **«Режим разработчика»** (Developer mode) в правом верхнем углу.
3. Нажмите **«Загрузить распакованное расширение»** (Load unpacked).
4. Выберите папку `extension/` из этого репозитория.
5. Откройте Chess.com или Lichess.org — расширение автоматически свяжется с локальным сервером `ws://127.0.0.1:9999`.

## 🧪 Тестирование и валидация надежности

В проекте реализован сквозной 5-уровневый тестовый комплекс (**201 тест, 100% pass rate**):
- **Unit тесты:** конфигурация, UCI-опции, алгоритмы времени, downloader.
- **Интеграционные тесты:** обмен сообщениями WebSocket, циклы размышления, сброс состояний.
- **Стресс- и Adversarial-тесты:** лавинная отправка FEN-строк, резкие обрывы связи при активном расчете, падение времени до 10 мс.
- **E2E Playwright тесты:** проверка парсинга DOM, ориентации доски и диалогов превращения пешек на офлайн-фикстурах Chess.com и Lichess.

### Запуск всех тестов:
```bash
python run_tests.py
```
